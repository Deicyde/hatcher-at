# Hatcher's auxiliary cell-attachment cover

Hatcher proves Proposition 1.26 by enlarging an indexed cell attachment with a
shared spine and one strip per cell. The enlargement retracts onto the original
attachment, while the strips turn the separate cone neighborhoods into one
contractible member of a binary open cover.

by the separate isomorphism node in the parent support chapter.
