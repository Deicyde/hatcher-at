# Covering maps inject path-homotopy classes

For a covering map `p : E → X` and endpoints `e₀,e₁ : E`, composition with
`p` is injective on endpoint-preserving path-homotopy classes from `e₀` to
`e₁`. Specializing to `e₀ = e₁` gives the injectivity clause of Hatcher's
Proposition 1.31.

This is exactly the pinned declaration
`IsCoveringMap.injective_path_homotopic_map`, whose docstring cites
Proposition 1.31.
