# The cone over a sphere forms a contractible good pair

For every n : ℕ, construct the actual cone-base pair Pₙ = (CSⁿ,Sⁿ) and prove that it is a good pair with contractible ambient cone. Use the existing retained cone model, where the cylinder coordinate r has apex at 0 and retained base at 1; Hatcher's coordinate is t = 1−r.

## Proof sketch

The completed cone-to-closed-disk homeomorphism identifies the retained boundary with the standard disk boundary, proving its embedding and closedness. Its open base neighborhood retracts to the boundary and supplies the good-pair witness. Transport closed-ball contractibility through the same homeomorphism. Include n = 0 and derive all geometric facts rather than assume them.
