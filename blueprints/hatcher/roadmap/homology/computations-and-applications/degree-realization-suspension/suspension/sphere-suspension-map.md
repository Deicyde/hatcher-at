# A sphere map induces its genuine suspension map

Define Sf : Sⁿ⁺¹ → Sⁿ⁺¹ by transporting the quotient map induced by Cf through the fixed cone-base quotient homeomorphism eₙ. On a suspension cylinder class it sends eₙ[x,r] to eₙ[f(x),r].

## Proof sketch

If qₙ : CSⁿ → Sⁿ⁺¹ is the quotient projection followed by eₙ, prove Sf ∘ qₙ = qₙ ∘ Cf on the ambient cone. Record the two fixed-pole equations and the identity/composition laws. The definition works for n = 0 and for arbitrary f, including constant maps.
