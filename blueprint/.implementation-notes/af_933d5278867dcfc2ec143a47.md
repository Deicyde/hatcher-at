# Implementation note: Only finitely many attaching degrees can be nonzero

## Remaining goal

For every n > 1 and actual n-cell α, the nonzero attaching-degree coefficients are contained in the finite family of (n−1)-cells met by the compact attaching image. Include arbitrary infinite cell families and constant attaching maps.

## Candidate declaration

`Hatcher.ClassicalCW.finiteAttachingDegreeSupport` is a naming proposal, not a verified declaration.

## Route

The source sphere is compact, so its image meets finitely many cells. If it misses β, the actual selected-cell collapse composite is constant and its positive-dimensional degree is zero.

## Fixed model and API constraints

Keep `positiveStandardDiskFundamentalClass`,
`positiveSkeletonCellFundamentalClass`, `skeletalCellFundamentalClass` and
the actual `cellularDifferential`. Their maps are in
`Hatcher/Singular/PointedWedgeHomology.lean` and
`Hatcher/Singular/Relative.lean`. Natural-number adjacent degrees are
(n+1,n); the outgoing degree-zero map is unaugmented and zero.

## Geometric support route

Use the compact actual attaching image and
`Hatcher.ClassicalCW.compact_subset_finite_subcomplex`, then show the selected
collapse map is constant outside that finite cell cover.
`degree_eq_zero_of_not_surjective` supplies the positive-dimensional zero
degree. Do not depend on the degree-coordinate equality for this geometric
support theorem. If an eventual implementation instead uses
`CWComplex.cellFrontier_subset_finite_openCell`, reconcile proof and informal
source dependencies to that actual route.
