# Implementation note: A complex projective stage attaches its actual even-dimensional disk

## Remaining goal

For n > 0, construct ℂPⁿ as the 2n-disk attachment to its actual coordinate copy of ℂPⁿ⁻¹. The attaching map sends a boundary vector to its complex line in ℂPⁿ⁻¹. Preserve the disk, boundary and coordinate-inclusion equations.

## Candidate declaration

`Hatcher.ComplexProjective.projectiveDiskAttachment` is a naming proposal, not a verified declaration.

## Route

The constructed characteristic disk and coordinate inclusion give the exact gluing relation. Their compact source and Hausdorff target make the induced attachment map a homeomorphism.

## Pinned Mathlib reuse

Use `Projectivization`, `Projectivization.mk_eq_mk_iff`, its actual linear
map/injectivity API and the generic quotient topology.
`Homeomorph.unitBall` already has exactly the radial formula required on
the characteristic-disk interior. Use `Complex.orthonormalBasisOneI` for
real/imaginary Euclidean coordinates. The phase quotient can use
`MulAction.isOpenQuotientMap_quotientMk` and
`t2Space_iff_of_isOpenQuotientMap`, or the proper-action quotient API after
proving the specific compact phase action is proper. Retain actual
representative equations and the n = 0 case.
