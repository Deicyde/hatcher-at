## Construction and proof

Private finite-vector lemmas split the squared norm at `Fin.last`, using
`EuclideanSpace.real_norm_sq_eq` and `Fin.sum_univ_castSucc`. The interval
bounds make the radicand nonnegative, giving the exact unit norm. Continuity
is proved coordinatewise, followed by `PiLp.continuous_toLp`; it includes
both endpoints because the real square root is continuous on all of ℝ.

On the existing cone prequotient, the retained base summand goes to north,
the explicit apex summand to south, and the cylinder summand to the displayed
formula. The endpoint equations prove invariance under the actual
`normalForm id`. `Quotient.lift` descends this map to the retained cone;
`isQuotientMap_quotientMk id` proves its continuity. The base is constant at
north, so `pushout.desc` gives `sphereConeQuotientMap` on the actual point
quotient. The pushout equations determine its projection and point values.

Every quotient point has a cylinder representative. Projection surjectivity
uses the nonemptiness derived in `sphereConeGoodPairData`. Quotient induction
represents a retained base at height one and the explicit apex at height
zero. Thus the zero-dimensional sphere uses the same construction.

Injectivity recovers height from the last coordinate. At height zero both
representatives are the actual apex; at height one both belong to the actual
collapsed fibre, using `pointQuotientProjection_preimage_point`. At every
interior height the square root is positive and scalar cancellation recovers
the actual source sphere point.

Surjectivity takes the target last coordinate `z`, recovers the horizontal
vector with `Fin.init`, and sets `r = (z + 1) / 2`. The finite norm equation
gives `sqrt (1 - z^2) = ‖w‖`. A zero horizontal vector covers both poles using
an actual sphere point chosen from the derived nonemptiness. Otherwise
`‖w‖⁻¹ • w` is a unit vector and the cylinder formula reconstructs the target
through `Fin.snoc_init_self`.

Compactness of the actual cone is transported through `diskHomeomorph`.
The continuous surjective actual point-quotient projection supplies compactness
of the quotient. `Continuous.homeoOfEquivCompactToT2` then makes the proved
bijective forward map a homeomorphism, preserving that fixed forward map.
The compact-complement construction in another article and the sibling
cone-map helpers are not used.
