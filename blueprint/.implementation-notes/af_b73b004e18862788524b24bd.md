# Implementation note: Characteristic disks of complex projective cells

## Remaining goal

For every n ∈ ℕ, construct the actual map from the closed real 2n-disk to ℂPⁿ given in complex coordinates by w ↦ [w,√(1−‖w‖²)]. It is surjective; its interior is the affine chart, and equal images mean equal points or boundary points related by a unit phase. Include the zero-dimensional disk.

## Candidate declaration

`Hatcher.ComplexProjective.projectiveCharacteristicMap` is a naming proposal, not a verified declaration.

## Route

Use real/imaginary Euclidean coordinates, the existing radial unit-ball homeomorphism and the projective affine chart. Normalized projective representatives give surjectivity and the exact boundary fiber relation.

## Pinned Mathlib reuse

Use `Projectivization`, `Projectivization.mk_eq_mk_iff`, its actual linear
map/injectivity API and the generic quotient topology.
`Homeomorph.unitBall` already has exactly the radial formula required on
the characteristic-disk interior. Use `Complex.orthonormalBasisOneI` for
real/imaginary Euclidean coordinates. The phase quotient can use
`MulAction.isOpenQuotientMap_quotientMk` and
`t2Space_iff_of_isOpenQuotientMap`, or the proper-action quotient API after
proving the specific compact phase action is proper. Retain actual
representative equations and the n = 0 case.
