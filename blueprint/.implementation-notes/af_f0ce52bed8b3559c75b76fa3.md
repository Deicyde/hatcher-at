# Compactifying a finite disjoint union gives the pointed wedge

## Candidate

`Hatcher/Singular/PointedWedgePointQuotient.lean` contains a complete proof
draft for these public targets:

- `Hatcher.Relative.finiteOnePointSigmaWedgeHomeomorph`;
- `Hatcher.Relative.finite_one_point_sigma_wedge_homeomorph_apply_coe`;
- `Hatcher.Relative.finite_one_point_sigma_wedge_homeomorph_apply_infty`.

The input is any finite family of locally compact Hausdorff spaces, bundled
as `TopCat` objects in a common universe. The output is the actual
`OnePoint (Σ i, X i)` homeomorphism to the existing `Hatcher.PointedWedge`
of the actual `OnePoint (X i)`, based at infinity. Empty index types and
empty or compact summands are included.

The selected private theorem `finiteOnePointSigmaWedgeExists` genuinely
constructs a homeomorphism satisfying both value equations. Its proof
contains the concrete quotient composition and empty-family construction.
The public noncomputable definition chooses this proved witness; the two
public theorems use `Classical.choose_spec` for its value equations. Those
equations determine its function on every point of `OnePoint (Σ i, X i)`.

## Construction

For a nonempty index type, use the sigma pointed pair of the compactified
spaces with basepoints infinity. The sigma coercion from `Σ i, X i` is an
open embedding whose range is the literal finite-point subspace `V`.
The range of the sigma pointed-pair embedding is exactly `Vᶜ`.

An embedding's homeomorphism onto its range identifies the sigma subspace
with `Vᶜ`. This gives a pair isomorphism with ambient component the
identity, then a point-quotient isomorphism through `pointQuotientMap`.
Compose the finite-point homeomorphism's `onePointCongr`, the inverse
`compactComplementQuotientOnePointHomeomorph`, the inverse transported
quotient isomorphism, and the existing
`pointQuotientSigmaPointedPairIsoPointedWedge`. Projection and point-inclusion
naturality and the existing comparison equations prove the two values.
The wedge comparison reuses the existing universal construction `desc`
and its `continuousMapEquiv`.

The existence proof splits by a dependent `if` on `Nonempty ι`.
In the empty branch, a local `IsEmpty ι` instance gives the actual constant
map to the wedge basepoint and the constant inverse to infinity. The
inverse laws eliminate the impossible finite or sigma representatives
through `OnePoint.rec` and `Quotient.inductionOn`. No public nonemptiness
hypothesis is added.
