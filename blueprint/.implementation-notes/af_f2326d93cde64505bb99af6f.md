# Local positive stretching deforms to a rotation through punctured maps

Use centered open exponential charts from Mathlib/Analysis/SpecialFunctions/Complex/Circle.lean, including bijOn_exp_Ioo_centeredArc. Circle.argEquiv is not a global homeomorphism. The formula is a homotopy only on the short common arc; a global homotopy from a k-power map to a rotation would be false for k not equal to 1.
