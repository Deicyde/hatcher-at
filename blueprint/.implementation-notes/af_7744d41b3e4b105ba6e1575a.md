# Degree of the actual component collapses

## Public API

`Hatcher.Sphere.sphere_ball_collapse_degree_unit n hn k i` states that the
actual component `i : Fin k` of `sphereBallPinch n hn k` has ordered signed
degree `1` or `-1`. Its degree is evaluated on
`TopCat.ofHom` of the already constructed continuous component map.

The supporting theorem
`Hatcher.Sphere.SphereBallPinchData.component_collapse_degree_eq_one_or_neg_one`
proves the same statement for every certified actual pinch-data bundle.
The canonical theorem specializes it to the existing canonical constructor.
At `k = 0` the component index is empty; no nonempty-index premise is added.

## Concrete proof

Choose `y₀` as the inverse stereographic image of Euclidean zero in the actual
punctured sphere at `D.b`. Its subtype membership proves `y₀.1 ≠ D.b`.
The actual chart inverse `(D.ballChart i).symm y₀` gives a point `x` in the
constructed open ball.

The component's chart equation proves `f x = y₀.1`. Its constant value off
that ball forces every preimage of this target into the same ball. Chart
injectivity then proves the actual set-theoretic fiber is exactly `{x}`.
`singletonFiberIsolatedPreimage` derives isolation from this proved equation.

Construct `LocalDegreeNeighborhood` with that actual open ball and the
derived central equation and uniqueness. Its `LocalHomeomorphData` uses the
literal open punctured target and exactly `D.ballChart i`, with its
pointwise agreement derived from `component_collapse_apply_ball`.
A local T2 instance is transported through `sphereULiftHomeomorph.{0}`.

The reached `localDegree_eq_one_or_neg_one_of_localHomeomorph` proves that
the signed local degree is a unit. The reached
`localDegree_eq_degree_of_fiber_eq_singleton` identifies it with the same
ordered global degree. No positive chart orientation or supplied degree,
fiber, or homeomorphism is a premise of the canonical result.
