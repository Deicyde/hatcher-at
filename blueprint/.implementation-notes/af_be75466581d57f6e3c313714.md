# Suspension pole fibers implementation

## Exact statement and objects

The public target is `Hatcher.Sphere.sphere_suspension_pole_fibers`:
the inverse images of the singleton existing north and south poles under
`sphereSuspensionMap n f` are exactly those same singleton sets.

Every declaration quantifies over `n : ℕ` and an arbitrary continuous map of
the actual `TopCat.sphere n`. It includes `n = 0` and constant maps. The
target is the actual next standard sphere, and `northPole n` and `southPole n`
already have this target type. No injectivity, surjectivity, nonconstancy,
positive-dimension, or extra geometric premise is used.

## Proof route

A selected private helper, `sphere_suspension_cylinder_representation`,
represents every actual next-sphere point y as `sphereConeCylinderPoint n x r`
and simultaneously represents its image as `sphereConeCylinderPoint n (f x) r`.
It applies the existing actual quotient-representative theorem to
`(sphereConeQuotientHomeomorph n).symm y`, then uses the actual quotient
projection and the reached E/cylinder and Sf/cylinder equations.

The existing representative helper derives nonemptiness from the proved
`sphereConeGoodPairData`. It supplies genuine representatives in the actual
retained cone and point quotient, including n=0. No surjectivity assumption
on f is introduced.

For an image at the north pole, compare `sphereConeCylinderPoint n (f x) r`
with `sphereConeCylinderPoint n (f x) 1`. The existing exact last-coordinate
height lemma forces `r = 1`. The original point is then the north pole by
the original-coordinate endpoint theorem. For the south pole, comparison
with height zero forces `r = 0`, and the same reasoning gives the south pole.

Both comparisons use the same actual point f(x) at two heights. They require
no injectivity of f. The reverse implications use the reached fixed-pole
theorems. Retained height one is the collapsed base/north pole; retained
height zero is the explicit apex/south pole, with Hatcher's coordinate
`t = 1 - r` unchanged.
