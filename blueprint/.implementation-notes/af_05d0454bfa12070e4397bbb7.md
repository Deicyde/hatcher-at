# Sphere suspension map implementation

## Actual construction

The main declaration is `Hatcher.Sphere.sphereSuspensionMap n f`, a continuous
self-map of the existing `TopCat.sphere (n + 1)`. Its function is exactly

`sphereConeQuotientHomeomorph n ∘ pointQuotientMap (sphereConePairMap n f) ∘
(sphereConeQuotientHomeomorph n).symm`.

The source and target of the induced point-quotient map are both the actual
`pointQuotient (sphereConePair n)`. The supporting
`sphereSuspensionProjection n` is the actual ambient cone projection followed
by the same fixed homeomorphism. Both are bundled directly with
`TopCat.ofHom`, with continuity supplied by the existing morphisms and the
homeomorphism's forward and inverse continuity.

All declarations quantify over `n : ℕ` and arbitrary continuous sphere maps,
including constant maps. The retained cylinder coordinate has apex zero and
base one; Hatcher's coordinate remains `t = 1 - r`. The exact existing
`northPole n` and `southPole n` lie in `TopCat.sphere (n + 1)`.

## Equations and proof route

The quotient equation cancels the fixed homeomorphism and its inverse. The
categorical ambient equation is

`sphereSuspensionProjection n ≫ sphereSuspensionMap n f =
sphereConeMap n f ≫ sphereSuspensionProjection n`.

It follows from `pointQuotientProjection_naturality` for the actual
`sphereConePairMap n f`. Explicit proof-local `change` exposes its ambient
component as the exact `sphereConeMap n f`.

The cylinder theorem evaluates this square at `cylinder id x r` and applies
`sphere_cone_map_cylinder`. Its public statement is precisely
`Sf (e[x,r]) = e[f(x),r]` using the actual quotient projection and fixed
homeomorphism. The existing `sphere_cone_quotient_homeomorph_cylinder`
rewrites these classes to `sphereConeCylinderPoint`, whose full square-root
Euclidean formula is already recorded by the quotient geometry.

The north-pole proof uses the canonical collapsed point and
`pointQuotientPointInclusion_naturality`. The south-pole proof uses the
actual fixed cone apex and its fixed-homeomorphism image. Both proofs include
`n = 0` and constant `f` without an additional nonemptiness premise.

The identity and composition proofs use `sphere_cone_pair_map_id`,
`sphere_cone_pair_map_comp`, `pointQuotientMap_id`, and
`pointQuotientMap_comp`, together with the two existing homeomorphism
cancellation equations. Composition applies `f` and then `g`, in the existing
TopCat order `f ≫ g`.
