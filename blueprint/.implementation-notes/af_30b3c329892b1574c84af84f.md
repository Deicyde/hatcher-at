# Implementation note: The even cells form the classical CW structure of complex projective space

## Remaining goal

For every n ∈ ℕ, construct a finite classical CW structure on the actual ℂPⁿ with exactly one cell in each dimension 0,2,…,2n and none in other dimensions. Use its actual coordinate strata and characteristic disks, including ℂP⁰.

## Candidate declaration

`Hatcher.ComplexProjective.projectiveClassicalCw` is a naming proposal, not a verified declaration.

## Route

Transport the disk charts to the classical cell models, verify disjoint interiors and boundary containment in lower coordinate strata, then use the finite classical CW constructor.

## Pinned Mathlib reuse

Use `Projectivization`, `Projectivization.mk_eq_mk_iff`, its actual linear
map/injectivity API and the generic quotient topology.
`Homeomorph.unitBall` already has exactly the radial formula required on
the characteristic-disk interior. Use `Complex.orthonormalBasisOneI` for
real/imaginary Euclidean coordinates. The phase quotient can use
`MulAction.isOpenQuotientMap_quotientMk` and
`t2Space_iff_of_isOpenQuotientMap`, or the proper-action quotient API after
proving the specific compact phase action is proper. Retain actual
representative equations and the n = 0 case.

## Classical cell model obligation

Use `CWComplex.mkFinite` and `finite_mkFinite` with actual partial
characteristic maps, disjoint interiors, boundary containment and cover.
The accepted comparison needs `Topology.CWComplex C`; an abstract
`TopCat.CWComplex` is insufficient. The classical sup-norm product cells
concatenate directly, including zero-dimensional factors.

`Hatcher.ClassicalCW.classicalCellArrowIso (n : ℕ)` is already the public
dimension-only classical/Euclidean cell-arrow comparison. Its disk and
boundary maps are available through the Arrow isomorphism components. Use
those maps directly and prove any genuinely needed interior convenience
equation. This is reuse of existing mathematics, without an orientation assertion.
