# Implementation note: Finite complex projective spaces

## Remaining goal

For n ∈ ℕ, define ℂPⁿ using the existing projectivization of ℂⁿ⁺¹: nonzero vectors modulo multiplication by nonzero complex scalars, with that quotient topology. Retain the actual vector-to-line map and identify ℂP⁰ with a single point.

## Candidate declaration

`Hatcher.ComplexProjective.complexProjectiveSpace` is a naming proposal, not a verified declaration.

## Route

Specialize the existing algebraic projectivization quotient and its line-subspace equivalence. In dimension one every nonzero vector spans the same complex line.

## Pinned Mathlib reuse

Use `Projectivization`, `Projectivization.mk_eq_mk_iff`, its actual linear
map/injectivity API and the generic quotient topology.
`Homeomorph.unitBall` already has exactly the radial formula required on
the characteristic-disk interior. Use `Complex.orthonormalBasisOneI` for
real/imaginary Euclidean coordinates. The phase quotient can use
`MulAction.isOpenQuotientMap_quotientMk` and
`t2Space_iff_of_isOpenQuotientMap`, or the proper-action quotient API after
proving the specific compact phase action is proper. Retain actual
representative equations and the n = 0 case.
