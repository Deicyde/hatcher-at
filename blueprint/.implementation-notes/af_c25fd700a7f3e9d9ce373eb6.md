# Geometric sphere-degree realization

## Uncompiled source candidate

`Hatcher.Sphere.sphere_degree_realization` constructs an actual continuous
sphere self-map of every signed integer degree in each positive dimension.
Its only inputs are the dimension, its positivity proof and the integer.

The proof splits integer constructors. For a natural integer it uses the
canonical geometric `signedSphereFoldMap` with its actual natural absolute
value as the number of balls and uniform sign +1. For a negative successor it
uses the absolute-value number of balls and uniform sign -1. The actual
self-map is the fold composed with the existing canonical sphere pinch;
no map or degree equation is supplied as a caller premise.

The accepted `sphere_signed_pinch_degree_sum` theorem supplies the degree
equation, then finite constant-sum and integer multiplication identities
compute the requested integer. At zero the family is empty; the existing
`SignedSphereFoldData.self_map_zero` identifies the same geometric witness
with the constant map at the actual omitted point. No finite output fiber of
that constant map or positive chart orientation is assumed.
