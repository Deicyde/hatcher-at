# Implementation note: Coefficients of the actual cellular differential

## Candidate

`Hatcher.ClassicalCW.cellularBoundaryCoordinates` is awaiting compilation
and independent review, together with its reconstruction and basis-witness
independence theorems. The definition applies the existing fixed target
cell-basis isomorphism to the actual adjacent cellular differential of a
characteristic-cell class. Its codomain is the finite-support integer
functions on the actual target cells.

## Route

The fixed basis theorem supplies the image of each standard vector. Extend
that equation to every integer multiple using additive homomorphisms, then
to every finite-support vector using `Finsupp.sum_single` and `map_sum`.
Cancelling the actual basis isomorphism reconstructs the differential.
`Finsupp.addHom_ext` proves that any other isomorphism with those prescribed
cell images has the same inverse and hence gives the same coordinates.

The result includes degree-zero targets, arbitrary cell sets and empty
cell families. It preserves all characteristic classes and actual cellular
maps, with no supplied differential matrix or finite-cell assumption.

## Search and imports

Native searches found no existing coordinate definition with this conclusion.
The reused skeletal basis and cellular complex are reachable prerequisites.
None of the nine copied packages has a usable shared Autoform index; pinned
Mathlib sources were inspected directly. `Finsupp.SMul`, `Finsupp.Ext` and
the finite-sum APIs are already imported through the existing group-colimit
chain, so no header or import change is needed.
