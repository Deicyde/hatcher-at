# Implementation note: The fixed disk class has a generating ordinary sphere boundary

## Remaining goal

For n > 1, the actual ordinary pair connecting map sends the fixed relative fundamental class of the standard n-disk to a generator of Hₙ₋₁(∂Dⁿ;ℤ) in the chosen integral model. Preserve the current relative disk class.

## Candidate declaration

`Hatcher.ClassicalCW.diskBoundaryGenerator` is a naming proposal, not a verified declaration.

## Route

Positive ordinary homology of the contractible disk vanishes on both sides of this connecting map. Pair exactness makes it an isomorphism, so the existing relative generator has a generating image.

## Fixed model and API constraints

Keep `positiveStandardDiskFundamentalClass`,
`positiveSkeletonCellFundamentalClass`, `skeletalCellFundamentalClass` and
the actual `cellularDifferential`. Their maps are in
`Hatcher/Singular/PointedWedgeHomology.lean` and
`Hatcher/Singular/Relative.lean`. Natural-number adjacent degrees are
(n+1,n); the outgoing degree-zero map is unaugmented and zero.

## Ordinary boundary and orientation

Use actual ordinary `pairConnecting`. For n > 1, ordinary homology of the
contractible disk vanishes on both sides, so this boundary is an isomorphism.
The reduced connecting isomorphism alone is not the required equation.
There is no existing ordered-generator compatibility across successive
sphere dimensions. Compare generators by their integral unit multiplier and
construct identity or `coordinateReflectionIso` accordingly, transported
through the chosen sphere/coefficients comparison. Preserve the fixed disk
class; do not infer Euclidean orientation from `StandardSimplexDisk` choices.
