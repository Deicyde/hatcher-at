# The path-class universal cover

Hatcher constructs a simply-connected cover of a path-connected, locally
path-connected, semilocally simply-connected space from homotopy classes of
paths starting at a basepoint. The topology here is generated directly by
Hatcher's basic sets `U[γ]`.
