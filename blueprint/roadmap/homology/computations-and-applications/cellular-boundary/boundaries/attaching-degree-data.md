# Degrees of the actual cellular attaching maps

For an n-cell α and an (n−1)-cell β with n > 1, construct the actual sphere self-map obtained from the orientation-compatible source identification, α’s attaching map and β’s complement-collapse quotient. Define its integer degree and retain this exact composition equation.

## Proof sketch

Compose the constructed maps, using the existing target cell quotient orientation, and lower the canonical sphere-coordinate lift to the standard degree model.
